DHCIP — Damri Human Capital Intelligence Platform

Sistem dashboard web untuk memantau performa karyawan DAMRI secara menyeluruh — dari ringkasan KPI perusahaan, detail penilaian tiap individu, pemetaan talenta lewat Nine Box Matrix, hingga rekomendasi perbaikan otomatis berbasis AI.

Live Demo — dhcip.my.id GitHub Profil

Empat Modul Utama

Semua aspek manajemen kinerja karyawan DAMRI dalam satu platform terintegrasi.

01

Dashboard

Ringkasan KPI seluruh karyawan dalam satu tampilan — agregasi performa lintas unit kerja secara real-time.

02

Employee Details

Profil kinerja individual: KPI, akhlak, kehadiran, dan penilaian 360° dari rekan, atasan, serta bawahan.

03

Nine Box Matrix

Pemetaan performa dan potensi pada tiga level: karyawan, leader, divisi, hingga direktorat.

04

AI Recommendation

Rekomendasi perbaikan otomatis berbasis Gemini Flash 2.5, disusun dari data kinerja tiap karyawan.

Arsitektur & Cakupan Data

Dibangun sebagai aplikasi web multi-layer dengan penilaian multi-sumber.

Struktur Sistem

  • Frontend — antarmuka dashboard interaktif (JavaScript / TypeScript)
  • Backend — layanan aplikasi Golang & PHP (CodeIgniter)
  • Database — MySQL untuk data karyawan, penilaian, dan histori KPI
  • Layanan AI — integrasi Gemini API untuk analisis dan rekomendasi

Aspek Penilaian

  • KPI — indikator kinerja utama per periode penilaian
  • Akhlak — dimens sikap dan perilaku kerja
  • Kehadiran — rekam disiplin kehadiran karyawan
  • Penilaian 360° — umpan balik dari rekan, atasan, dan bawahan

Teknologi yang Digunakan

Stack yang menopang seluruh platform.

JavaScript / TypeScript Golang PHP CodeIgniter Gemini API MySQL
